                            USER INTERACTIONS

1. STARTUP
   └─> Window opens → Shows empty table → Ready to scan

2. CLICK "START SCANNING"
   └─> Button disables (grayed out)
   └─> Progress bar appears and animates 0-100%
   └─> Table populates with results as they come in
   └─> Status message updates: "✅ Scan complete!"

3. RESULTS APPEAR
   └─> Table sorted by highest reward% first
   └─> Shows 210 stocks analyzed, X stocks matched
   └─> Average R:R ratio displayed at bottom

4. CLICK "EXPORT TO EXCEL"
   └─> Excel file created with timestamp
   └─> Success message shown
   └─> File ready to open and analyze

5. SORT/FILTER (Built-in)
   └─> Click column header to sort
   └─> View best opportunities at top
   └─> Print for reference if needed

                        INFORMATION DISPLAYED

┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  Stock      = Equity symbol (e.g., INFY, TCS, RELIANCE)                │
│  Price      = Current market price (Entry point)                        │
│  SL         = Stop Loss price (10-day swing low)                        │
│  SL %       = Risk percentage from entry                               │
│  T1         = First target (Entry + 2×Risk)                           │
│  T2         = Primary target (Entry + 3×Risk)                         │
│  T3         = Aggressive target (Entry + 5×Risk)                      │
│  Risk       = Rupees at risk (Entry - SL)                             │
│  Target %   = Reward percentage to T2                                  │
│  R:R        = Risk:Reward ratio (higher is better)                    │
│  Trend      = "Strong Uptrend" or "Weak"                              │
│  CAR        = "Positive" or "Negative" confirmation                   │
│  Date       = Scan date                                                │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════════════════════════════

                    FILTERING CRITERIA (Behind the scenes)

All stocks MUST pass ALL 4 filters:
  1. ✅ Price > 30-day moving average
  2. ✅ Price > 50-day moving average
  3. ✅ Price > 200-day moving average
  4. ✅ CAR (Cumulative Average Return) is positive

Only stocks that pass ALL criteria appear in results!
