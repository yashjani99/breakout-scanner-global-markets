║   BUILDING WINDOWS EXE - STEP BY STEP                         ║
╚═══════════════════════════════════════════════════════════════╝

REQUIREMENTS:
✓ Windows 7 or later
✓ Python 3.8+ installed (from python.org)
✓ Internet connection

STEPS:
═════════════════════════════════════════════════════════════════

1. INSTALL PYTHON (If not already installed)
   ─────────────────────────────────────────
   a) Download: https://www.python.org/downloads/
   b) Run installer
   c) ✓ IMPORTANT: Check "Add Python to PATH"
   d) Click Install
   e) Restart computer

2. OPEN COMMAND PROMPT
   ─────────────────────────────────────────
   a) Press: Windows + R
   b) Type: cmd
   c) Press: Enter
   d) Navigate to folder: cd "path\to\Trading India"

3. INSTALL DEPENDENCIES
   ─────────────────────────────────────────
   Copy & paste this command:
   
   pip install PyQt5 yfinance pandas openpyxl pyinstaller
   
   Press Enter and wait for completion.

4. BUILD THE EXE
   ─────────────────────────────────────────
   Copy & paste this command:
   
   pyinstaller --onefile --windowed --name="BreakoutScanner" breakout_scanner_gui.py
   
   Wait 3-5 minutes for build to complete.

5. FIND YOUR EXE
   ─────────────────────────────────────────
   Location: dist\BreakoutScanner.exe
   
   This is your executable file!

6. CREATE SHORTCUT (Optional)
   ─────────────────────────────────────────
   a) Right-click: BreakoutScanner.exe
   b) Send to: Desktop (create shortcut)
   c) Now you can run from desktop

7. SHARE WITH OTHERS
   ─────────────────────────────────────────
   Just send them: dist\BreakoutScanner.exe
   
   They can run it directly (no Python needed!)

═════════════════════════════════════════════════════════════════

TROUBLESHOOTING:

Q: "Python not found"
A: Reinstall Python. Check "Add Python to PATH" during setup.

Q: "ModuleNotFoundError"
A: Run step 3 again. Copy the entire command exactly.

Q: "Build failed"
A: Make sure you're in the correct folder with breakout_scanner_gui.py

Q: "EXE won't run"
A: Try running in Administrator mode. Check Windows Defender.
